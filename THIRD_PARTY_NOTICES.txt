Where each one ends up
-------------------------------------------------------------------------------

* MinHook is compiled into dlls/main.dll (vendored submodule
  third_party/minhook). BSD 2-Clause asks for the copyright notice, the list
  of conditions and the disclaimer to be reproduced in binary form; that is
  what this file does.

* UE4SS is NOT shipped in this archive. dlls/main.dll is built against the
  UE4SS v3.0.1-944-g0196ef29 public headers and, at run time, links against
  the UE4SS.dll that the server's own mod pack installs. Its MIT text is
  reproduced because the binary is designed to be loaded by it.

* {fmt} 11.2.0 is compiled into dlls/main.dll. The copy used is
  _ue4ss_ref/third_party/fmt/, which is upstream fmt 11.2.0 with the UE
  'check'-macro patch applied by RE-UE4SS's build; file hashes and the patch
  hunks are recorded in that directory's PROVENANCE.md.

* The Coyote (DG-LAB) protocol documents referenced by the source tree are
  not part of this archive or of the repository. They are published by the
  vendor for hobbyist use and are not covered by the MIT license above.
  The repository only records the upstream URL, the snapshot commit id and
  per-file sha256 sums, in re/reference/dglab-bluetooth-protocol/PROVENANCE.md.
